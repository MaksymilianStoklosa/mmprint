# MM Print

Strona drukarni online z katalogiem produktow i kalkulatorem cen.

## Uruchomienie

1. Zainstaluj zaleznosci.
2. Uruchom aplikacje.

```bash
npm install
npm run dev
```

## Funkcje

- katalog produktow,
- kalkulator orientacyjnej ceny,
- sekcje informacyjne o firmie i realizacji zamowien,
- responsywny układ strony.

## Stan implementacji

- katalog produktow jest zdefiniowany lokalnie w kodzie,
- kalkulator renderuje pola formularza dla kazdego produktu,
- silnik cen opiera sie o reguly cenowe i doplaty.
